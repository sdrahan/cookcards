# Documentation

This directory contains project documentation.

## Structure
- `docs/specs/`: feature contracts and expected behavior.
- `docs/tasks/open/`: ready-to-implement tasks.
- `docs/tasks/done/`: completed task records.
- `docs/changelog.md`: condensed history of spec-impacting changes and decisions.
- `docs/01-vision.md`: product intent and audience.
- `docs/02-scope-nongoals.md`: in-scope and intentionally excluded areas.
- `docs/03-architecture.md`: system shape and deployment model.
- `docs/04-security-privacy.md`: security and privacy constraints.

## Usage
- To implement a change, start from the task in `docs/tasks/open/` and the referenced spec(s).
- To understand current behavior, read `docs/specs/` first.
- After spec-impacting work, append a short entry to `docs/changelog.md`.
- For cross-file precedence and workflow rules, use `AGENTS.md`.
